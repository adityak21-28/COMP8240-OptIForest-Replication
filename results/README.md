# Results directory

Scripts write raw run-level metrics, summary tables, logs and metadata here.

- `isolation_forest_baseline_runs.csv`: locally measured scikit-learn baseline results. These are **not OptIForest results**.
- `official_*.txt` and `official_*.json`: captured output and run metadata from the authors' upstream OptIForest repository.
- Final report values must be copied from verified output, not guessed.

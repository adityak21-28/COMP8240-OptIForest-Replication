# Synthetic dataset terms

`data/synthetic_anomaly_benchmark_v1.csv` is generated by this project's own script and contains no rows copied from an external real-person dataset. For the project repository it may be shared under the Creative Commons CC BY 4.0 terms, with attribution to Aditya Kamble and a citation to the repository. The data-generator code is covered by the repository's MIT licence.

This note does not change access or licence terms for external datasets such as OpenML Annthyroid or the authors' upstream OptIForest repository. Check each third-party dataset's own terms before redistribution.
